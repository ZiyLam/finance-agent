WEB API ACCESS

Web API 访问令牌

仅在远程访问，或服务端设置了 AGENT_WEB_ACCESS_TOKEN 时需要。它只保存在本次浏览器会话中，与下方的数据源令牌相互独立。

本机开发提醒：当前令牌回显仅允许从 127.0.0.1 访问，且不会写入浏览器持久化存储。环境变量优先于本地加密令牌；删除本地令牌不会修改环境变量。准备远程访问、共享屏幕或提交代码前，请恢复为不回显。
启用与连通性：只有标记为“已启用”的提供方才会进入 Agent、确定性研究或 LLM 调用；停用后也不会进行连通测试。页面不会自动访问远端，手动测试可能占用一次供应商请求额度，千帆测试会产生一次极小模型调用。
